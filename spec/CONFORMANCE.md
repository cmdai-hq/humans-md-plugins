## Deferred requirements and evidence boundary

State activation, provenance, the 2-hour default/12-hour maximum expiry, expiry withdrawal and activation ordering are **deferred**. They are not “fixed by tests”: the current acceptance criterion is that no active or caller-selected path remains. Organization hosting, presence orchestration and strong identity proof are also outside this contract's implementation scope.

The structural checker validates artifact consistency, schema compilation, valid examples and expected output shapes. It does not implement the normative reader, compiler, merge or renderer and does not run models. The delivered reference suite exercises byte entrances, reader/writer parsing, withholding, experimental merging and CLI rejection; failures require investigation. Native-adapter and model trials remain separate pending evidence. Runtime conformance and independent review must be reported separately with concrete outputs; an expected vector is not evidence that a consumer passes it.
